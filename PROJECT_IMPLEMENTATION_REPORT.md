# Project Implementation Report

**Project:** Adaptive Practice Sequencing Model  
**Repository:** `recommendation_model`  
**Domain:** AI-driven pronunciation practice recommendation for early learners  

---

## 1) Actual Final Implementation Details of This Component

This project implements a **hybrid adaptive recommendation system** that decides the next practice word for a child based on performance.

- **Exact model used**
  - `DecisionTreeClassifier` from scikit-learn
  - Key params: `max_depth=5`, `class_weight='balanced'`, `random_state=42`
  - Saved model artifact: `policy_model.pkl`

- **System behavior**
  - ML predicts pedagogical actions such as:
    - `REPEAT`
    - `SWITCH_EASIER`
    - `SAME_LEVEL_NEW`
    - `ADVANCE_LEVEL`
    - `REVIEW_MASTERED`
  - If ML prediction is unavailable/fails, system falls back to rule-based logic.

- **Features used for prediction**
  - `last_score`
  - `avg_last3`
  - `consecutive_fails`
  - `attempts`
  - `current_level`
  - `percent_level_mastered`
  - `word_difficulty`

- **Frameworks/libraries used**
  - Python
  - Scikit-learn (model training + evaluation)
  - Pandas / NumPy (data handling and feature arrays)
  - Matplotlib (plots)
  - Pickle (model persistence)
  - Graphviz DOT export (tree structure)

- **Backend / database / frontend used**
  - Current implementation is a **Python ML pipeline + simulation/demo**.
  - No production database is connected in this repository.
  - No full frontend app in this repository; demonstration is via CLI simulation (`demo_ml.py`).

- **Cloud or local inference**
  - Local inference only (`policy_model.pkl` loaded directly).
  - No cloud deployment in this project version.

## 2) Dataset Details

- **Data source**
  - Synthetic training dataset generated by simulation (`generate_data.py`), based on pedagogical rules from `AdaptiveLearningPath`.

- **How samples are produced**
  - Multiple simulated sessions and steps generate feature-action examples.
  - Default generator config: `num_sessions=10000`, `steps_per_session=20`.
  - The script writes labeled records into `training_data.csv`.

- **Target label**
  - `action_label` (the recommended pedagogical action).

- **Train/test split**
  - Stratified split in training script:
    - 80% training
    - 20% testing
  - Implemented with `train_test_split(..., stratify=y, random_state=42)`.

- **Collection ethics / consent**
  - Not applicable to current training dataset because it is synthetically generated in code.

## 3) Actual Preprocessing / Pipeline

Real pipeline used in this repository:

1. **Generate training rows** using simulated student sessions (`generate_data.py`)
2. **Compute state features** from learner history (`adaptive_model.py`)
3. **Create labeled dataset** where labels come from rule-based expert policy
4. **Split data** into train/test (`train_model.py`)
5. **Train decision tree classifier**
6. **Evaluate model** with classification report and confusion matrix
7. **Export artifacts**:
   - `policy_model.pkl`
   - `plots/classification_report.txt`
   - `plots/confusion_matrix.png`
   - `plots/feature_importance.png`
   - `plots/tree.dot`
   - `plots/tree_rules.txt`
8. **Run demo inference** (`demo_ml.py`) to simulate adaptive recommendations

> Note: This project does not perform audio-level preprocessing (e.g., MFCC/noise filtering) because the training dataset is generated from simulated student state transitions rather than raw speech audio.

## 7) Limitations Observed

- Training data is simulation-generated; real child speech interactions are not yet included.
- Class imbalance affects minority class behavior (e.g., `REVIEW_MASTERED` recall issue).
- The model is a single decision tree; performance may improve with ensembles or calibrated policies.
- No deployed service/API layer in this repository version.
